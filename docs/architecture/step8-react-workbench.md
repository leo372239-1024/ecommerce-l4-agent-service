# 步骤8：React 客户与客服工作台

日期：2026-10-09。React / TypeScript / Ant Design 工作台接入步骤4–7的真实后端；商家操作仍为模拟，模型、向量与精排 API 真实。浏览器实测与限制见 [交付审查](../delivery/step8-react-workbench-review.md)。

## 登录与角色

前端启动先读取 `/api/v1/auth/session`，使用同源 HttpOnly Cookie 和会话返回的 CSRF Token。Token 只存在 React 内存，不写 localStorage / sessionStorage。`/auth/config` 只返回演示登录与组织登录是否启用；生产禁用演示登录。已配置 OIDC 时显示组织登录入口，协议、账户映射与权限仍由步骤7后端处理。

| 角色 | 页面与操作 |
| --- | --- |
| 客户 | 自己的任务、客户确认、自己的工单、授权知识、自己的记忆、提取及查看 AWM |
| 客服 | 授权工单接管/对账/关闭、授权知识检索与自己有权管理的资料 |
| 主管 | 工单、主管审批、授权知识管理和共享政策审核、AWM 验证/批准/停用 |

隐藏菜单只是交互层约束。客户/租户、资料范围、操作版本与岗位权限由每个 API 再校验。401 或 CSRF 失效会清空工作台并显示登录页；退出也清除当前页面状态。不会把客户数据或模型密钥编码到前端包。

## 任务与恢复

提交任务通过 `/runs`，相同内容的未确认请求保留原 `Idempotency-Key`；成功后生成下一次提交键。操作按钮有同步锁，防止同一组件重复提交。网络超时显示结果未确认并刷新事实，不自动重发审批或商家写操作。补充订单、取消和审批携带 `expected_revision`；冲突刷新后重新审查。

列表展示最近100个可访问任务并分页，选中编号写入 `#run=UUID`，刷新可恢复该任务。详情每3秒读取权威快照，列表与其他管理页每5秒刷新。计划、依赖、查询/写入风险与核验状态从公开结构化事件投影，不展示模型原始推理或系统提示。

SSE 用 `fetch` 流式读取，发送 `Last-Event-ID`。解码器支持跨 UTF-8 字节边界、CRLF、心跳、跨帧及多行 data；只有完整且合法的帧才推进游标。事件按序号去重，遇到缺口拒绝推进并重新连接。连接故障按1–15秒退避，35秒观察窗口重新建立流；Nginx 关闭代理缓冲并将上游连接超时限制为5秒。

快照的 generation / event_seq 变化会重新启动流，因此其他页面完成审批后仍能继续步骤。等待补充/审批及终态追平后停止持续连接，保留快照轮询。浏览器刷新时内存游标从0重放数据库事件，再还原计划；没有保存敏感事件缓存。切换任务会丢弃旧流和旧缓冲。

## 审批与人工工单

审批卡展示订单、动作、金额、实体/政策版本、有效期、是否需要主管，二次确认后提交 revision。客户确认与主管批准是独立动作。批准后的事实以操作账本和商家回执为准，页面不会把“已确认”显示为“已执行”。

工单展示失败记录、业务证据、步骤与操作状态；客服携带工单 revision 接管、权威对账并填写处理结论后关闭。授权工单详情增加 `operation_receipts`：在已通过工单可见性检查后，从同租户且同 workflow 的提案与账本读取最新回执。客服无需、也不能直接读取客户原始任务。客户能看到自己工单的最终结论。

## 记忆、知识与 AWM

记忆页读取真实自动记忆设置，支持明确回复/渠道/语言偏好与1–365天保留期、删除单条、遗忘全部。遗忘同时关闭自动记忆；历史摘要始终标注仅供参考，不能替代当前工具事实。

知识页支持 UTF-8 TXT / Markdown 上传、文本创建、版本替换、失败重试、主管审核与删除；范围、可见角色、生效/过期时间可配置。文件解析有4 MB读取预算、100万字符与1500段上限；整请求上限仍为100 MiB。PDF / DOCX / OCR 未接入。`can_manage` 是后端计算的能力，前端据此展示按钮，实际变更依旧校验 owner / tenant / role / expected_version。

检索和任务回答可打开引用抽屉。每次打开都会按 chunk_id 重新请求 `/knowledge/evidence/{id}`，校验当前权限、版本、生效/过期状态，展示原文、来源、版本、时间和摘要哈希。替换/删除后历史引用失效时明确提示重新检索，不继续展示旧资料为当前证据。所有外部文本通过 React 转义展示。

AWM 从支持范围内已成功且核验过的订单/售后任务提取候选。主管执行结构重放验证、批准或停用；批准后可预览和下载 Skill。模板是受控 typed DAG，保留当前权限、政策、确认及对账边界，不执行上传脚本。停用模板不能继续导出。结构通过不代表业务效果提升；正式成对评测留到步骤9。
